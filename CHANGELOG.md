# Changelog

## 0.1.0

The first Android version, built on the same core as Dayweave 0.1.0 for Ubuntu.

### Added

- Today, with the day's weave, overdue tasks, today's tasks and habits, upcoming deadlines and the week
- Tasks with priorities, statuses, projects, tags, subtasks, repeats and reminders
- Habits to build, quit, measure or check off, with streaks, history and a heatmap
- Projects with progress and deadlines
- A calendar month with a daily agenda
- Focus sessions and breaks with a live notification
- Analytics for tasks, habits and focus time
- Reminders on the minute, with Complete and Snooze on the notification
- Backups, database copies, CSV exports and restore through Android's file picker
- Updates from GitHub Releases, checked against a checksum and the app's signing key
- Light and dark themes, and a New task launcher shortcut
